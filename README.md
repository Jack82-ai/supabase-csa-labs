## Working through a lab

1. Establish the customer scenario and a concrete working outcome.
2. Set up an isolated training project with synthetic data.
3. Build in small steps, discussing the relevant database decisions as we go.
4. Verify the behavior with repeatable checks.
5. Record setup commands, design choices, test results, and cleanup instructions in that lab's README.

## Public repository boundaries

Use only local or isolated training databases. Never connect exercises to production applications or use production data. Keep credentials and local environment files out of Git. Preserve upstream license notices and record the source commit when importing example code.
